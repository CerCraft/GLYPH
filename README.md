# GLYPH — Сканер текста с экрана

[![Manifest V3](https://img.shields.io/badge/Manifest-V3-5b8def?style=flat-square)](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3) [![Сборка](https://img.shields.io/badge/build-Vite-8b5cf6?style=flat-square)](https://github.com/CerCraft/GLYPH)

**GLYPH** — компактное расширение для Chrome и Edge. Выделите область страницы, чтобы распознать и скопировать текст. OCR выполняется локально на устройстве с помощью Tesseract.js.

**Репозиторий:** [github.com/CerCraft/GLYPH](https://github.com/CerCraft/GLYPH)

## Возможности

- Снимок видимой вкладки и выделение нужного фрагмента поверх страницы.
- Распознавание на русском, английском или обоих языках одновременно.
- Автокопирование текста и небольшое окно предпросмотра.
- Запуск по `Alt+Shift+S` или кнопкой в окне расширения; клавишу можно переназначить.
- Извлечение текста из изображений, canvas, видео и отрисованных страниц PDF.
- Снимок и распознанный текст не отправляются на сервер.

## Как выглядит интерфейс

### Окно расширения

![Окно расширения GLYPH](docs/screenshots/popup.png)

В окне расширения можно сразу начать выделение, выбрать язык, включить автокопирование или предпросмотр и открыть настройки сочетания клавиш.

### Выделение и результат

![Выделение области и окно результата](docs/screenshots/selection.png)

Перетащите указатель по снимку страницы. Внутри рамки остаётся исходное изображение, а область за её пределами затемняется. Нажмите `Esc`, чтобы отменить выбор. После распознавания проверьте текст в небольшом окне и нажмите **Копировать**.

## Сборка

Требуются Node.js 20+ и npm.

```bash
git clone https://github.com/CerCraft/GLYPH.git
cd GLYPH
npm install
npm run build
```

Сборка создаёт готовую к загрузке папку `dist/`; она намеренно исключена из Git, поскольку полностью воспроизводится командой `npm run build`. При первой сборке загружаются модели Tesseract для русского и английского языков. Они кэшируются локально и включаются в `dist/` вместе с worker и WebAssembly core. После установки распознавание не требует сети.

## Установка в Chrome или Edge

1. Выполните команды сборки.
2. Откройте `chrome://extensions` или `edge://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `dist/`.
5. Закрепите **GLYPH** на панели браузера.

## Использование

1. Откройте страницу с нужным текстом.
2. Нажмите `Alt+Shift+S` или откройте **GLYPH** и выберите **Выделить область**.
3. Обведите текст мышью или сенсорным указателем. Для отмены нажмите `Esc`.
4. Скопируйте распознанный текст из окна предпросмотра. Если предпросмотр отключён, результат появится в буфере обмена при включённом автокопировании.

В окне расширения доступны варианты языка **Русский + Английский**, **Только русский**, **Только английский**, переключатели **Автокопирование в буфер** и **Окно предпросмотра**, а также ссылка **Настроить клавишу**. Браузер может не назначить стандартное сочетание, если оно уже занято; проверьте его на странице сочетаний клавиш.

## Ограничения

Внутренние страницы браузера и магазины расширений недоступны для захвата. На такой странице GLYPH покажет сообщение **«Недоступно на системных страницах браузера»**. Перейдите на обычный сайт и повторите действие.

## Технологии

React, TypeScript, Vite, esbuild, Manifest V3 и Tesseract.js.
